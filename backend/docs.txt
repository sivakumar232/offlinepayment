    "message": "User created successfully."
}
2. 🏦 Bank Account Creation
This step establishes the money (account_id and balance). Requires user_id from Step 1.

Detail	Value
Method	POST
Endpoint	http://localhost:3000/api/bank/accounts
Headers	Content-Type: application/json

Export to Sheets

Body (JSON)

JSON

{
    "user_id": "USER1",
    "initial_balance": 50000.00
}
Expected Response

Status Code: 201 Created

Action: SAVE the account_id (e.g., ACC1) for the next step.

JSON

{
    "account_id": "ACC1",
    "user_id": "USER1",
    "balance": 50000,
    "message": "Bank account created and initialized successfully."
}
3. 💳 Wallet Creation & Linking
This step establishes spending permission (wallet_id). Requires user_id and account_id.

Detail	Value
Method	POST
Endpoint	http://localhost:3000/api/wallets
Headers	Content-Type: application/json

Export to Sheets

Body (JSON)

JSON

{
    "user_id": "USER1",
    "account_id": "ACC1",
    "public_key": "MOCK_PK_ZORO_987654",
    "device_id": "DEV-ZORO-SWORD"
}
Expected Response

Status Code: 201 Created

Action: SAVE the wallet_id (e.g., WALLET1).

JSON

{
    "wallet_id": "WALLET1",
    "offline_limit": 500,
    "message": "Wallet created and linked successfully."
}
4. 📱 Device Registration
This step finalizes the Root of Trust. Requires wallet_id, device_id, and public_key.

Detail	Value
Method	POST
Endpoint	http://localhost:3000/api/devices/register
Headers	Content-Type: application/json

Export to Sheets

Body (JSON)

JSON

{
    "wallet_id": "WALLET1",
    "device_id": "DEV-ZORO-SWORD",
    "public_key": "MOCK_PK_ZORO_987654"
}
Expected Response

Status Code: 201 Created

Action: CONFIRM the final setup is complete.

JSON

{
    "message": "Device registered successfully. Stage 0 complete."
}
